# Многопоточный конвейер для 1С

**Многопоточная обработка данных и управляемые очереди в вашей конфигурации.**

Многопоточный конвейер — MTP / Multi-threaded pipeline — встраиваемый фреймворк для разработчиков 1С. Он помогает выполнять задачи параллельно, переносить тяжёлые операции в фон и сглаживать пиковые нагрузки.

Вы пишете логику обработки данных, а MTP выполняет её в многопоточном режиме: запускает фоновые задания, контролирует выполнение, сохраняет ошибки и организует повторные попытки.

**[Скачать релиз](https://github.com/ASZykov/1c-mtp/releases) · [Установка](https://github.com/ASZykov/1c-mtp/wiki/Установка) · [Документация](https://github.com/ASZykov/1c-mtp/wiki)**

## Для чего нужен MTP

Многопоточный конвейер используется там, где нужны:
- **Параллельные вычисления.** Увеличение производительности высоконагруженных систем за счет отказоустойчивой многопоточной обработки данных.
- **Асинхронная обработка.** Механика отложенного фонового исполнения заданий, повышение скорости работы интерфейса пользователя.
- **Внутренние очереди в 1С.** Реализация в 1С классической концепции *Internal Message Queue*. Стабилизация нагрузки на систему.

| Ваша задача | Как помогает MTP |
| --- | --- |
| Обработать тысячи объектов: выполнить расчёты, создать документы или загрузить данные | Вы разделяете объекты на независимые порции — пакеты данных. MTP обрабатывает разные пакеты параллельно в нескольких фоновых заданиях. |
| Отложенное выполнение тяжёлой операции | Позволяет поставить задание в очередь и выполнить его в фоне, не блокируя сеанс пользователя. |
| Сглаживание пиковых нагрузок | Сохраняет задания в очереди и выполняет их с настроенным ограничением параллелизма. |
| Повторить выполнение задания после временной ошибки | Автоматически повторяет обработку при настроенных ошибках, например блокировках или недоступности сервиса. Интервал и число попыток задаются в настройках. |
| Не прерывать обработку всех объектов при ошибке одного | Сохраняет ошибки и позволяет повторно обработать отдельные задания после устранения причины ошибки. |

Подробнее: [многопоточная и асинхронная обработка](https://github.com/ASZykov/1c-mtp/wiki/Многопоточная-и-асинхронная-обработка), [внутренние очереди в 1С](https://github.com/ASZykov/1c-mtp/wiki/Внутренние-очереди-в-1С).

## Основные возможности

- **Параллельная обработка.** Настройка количества рабочих фоновых заданий и объёма обрабатываемых порций.
- **Управление нагрузкой.** Ограничение параллелизма отдельно для каждого способа обработки.
- **Настройка через интерфейс.** Управление способами обработки и инструментами групповой работы с пакетами.
- **Контроль выполнения.** Отслеживание работы фоновых заданий и выявление проблем обработки.
- **Повторные попытки.** Настройка ошибок, интервалов и максимального числа повторов.
- **Диагностика и отладка.** Журнал обработки пакетов, ручной запуск отдельных пакетов в сеансе пользователя.
- **Визуализация.** Логирование фоновых заданий и анализ их работы на диаграмме Ганта.

## Как это работает

В основе MTP — два понятия:

- **Пакет данных** — отдельное задание с данными для обработки: например, ссылкой на документ, структурой параметров или JSON входящего сообщения.
- **Способ обработки** — настройки выполнения заданий: какой обработчик вызвать, сколько фоновых заданий запускать одновременно и как повторять обработку при ошибках.

Ваш код создаёт задания - пакеты данных. Конвейер выбирает их из очереди и многопоточно их обрабатывает, поддерживая заданное число параллельных рабочих фоновых заданий.

## Проверено на практике

MTP используется в высоконагруженных системах предприятий розничной торговли, электроэнергетики и логистики.

<img width="96" height="96" alt="image" src="https://github.com/user-attachments/assets/2ccac5ae-1047-4a8b-83d1-b4138999d045" />

В СДЭК конвейер стал внутренним стандартом разработки, он встроен во все базы 1С компании. Среди решаемых задач:  
- обработка данных, поступающих из RabbitMQ;
- восстановление последовательностей взаиморасчётов;
- обмены между системами 1С;
- трансляция данных в управленческий учёт и МСФО;
- формирование актов и отправка клиентам;
- закрытие расчётных периодов;
- взаимодействие с внешними сервисами.

На базе MTP построены две биллинговые платформы СДЭК. [**Подробнее на infostart.ru**](https://infostart.ru/pm/2718550/)

## Требования и внедрение

- Платформа **1С:Предприятие 8.3.27 и новее**.
- Поддерживаются интерфейс **«Такси»** и режим интерфейса **8.5**.
- Многопоточный конвейер может быть встроен в любую конфигурацию 1С двумя способами:
    - через сравнение и объединение с файлом поставки `.cf`.
    - подключением расширения `.cfe`.
