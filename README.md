## О проекте

Многопоточный конвейер (MTP) - предназначен для решения двух фундаментальных задач:
1. **Распараллеливание вычислений**  
    Увеличение производительности высоконагруженных систем. Реализация отказоустойчивой многопоточной обработки данных.
2. **Асинхронная обработка данных**  
    Механика отложенного исполнения заданий. Организация и управление внутренними очередями в 1С. Реализация функций брокеров сообщений во внутреннем контуре автоматизации.

Многопоточный конвейер - это встраиваемая конфигурация 1С (фреймворк). Конфигурация предназначена для использования на платформе 1С Предприятие 8 на версии 8.3.27 и старше. Интерфейс конфигурации поддерживает режим "Такси" и режим интерфейса 8.5. 

Порядок встраивания конфигурации, настройки, инструкции описаны в [Wiki](https://github.com/ASZykov/1c-mtp/wiki) проекта.
