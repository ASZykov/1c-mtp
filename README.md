## О проекте

Встраиваемая конфигурация 1С 8 "Многопоточный конвейер" (MTP) редакция 3. Конфигурация предназначена для использования на платформе 1С Предприятие 8 на версии 8.3.27 и старше. Интерфейс конфигурации поддерживает режим "Такси" и режим интерфейса 8.5. 

Многопоточный конвейер - предназначен для решения двух фундаментальных задач:
1. **Распараллеливание вычислений**  
    Увеличение производительности высоконагруженных систем. Реализация отказоустойчивой многопоточной обработки данных.
2. **Асинхронная обработка данных**  
    Механика отложенного исполнения заданий. Организация и управление внутренними очередями в 1С. Реализация функций брокеров сообщений во внутреннем контуре автоматизации.

В состав конфигурации входят 2 подсистемы:
- Многопоточный конвейер. Позволяет быстро организовать многопоточную, отказоустойчивую обработку произвольных данных.
- Константы. Позволяет организовать удобное ретроспективное хранение констант.

Порядок встраивания конфигурации описан в документации проекта по ссылке https://github.com/ASZykov/1c-mtp/wiki
