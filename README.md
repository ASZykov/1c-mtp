## О проекте

Многопоточный конвейер (MTP) - предназначен для решения трех фундаментальных задач:
1. **Параллельные вычисления.**  
    Увеличение производительности высоконагруженных систем за счет отказоустойчивой многопоточной обработки данных.
2. **Асинхронная обработка.**  
    Механика отложенного фонового исполнения заданий, повышение скорости работы интерфейса пользователя.
3. **Внутренние очереди в 1С.**  
    Реализация в 1С классической концепции *Internal Message Queue*. Стабилизация нагрузки на систему.

Многопоточный конвейер - это встраиваемая конфигурация 1С (фреймворк). Предназначена для использования на платформе 1С Предприятие 8 на версии 8.3.27 и старше. Интерфейс конфигурации поддерживает режим "Такси" и режим интерфейса 8.5. 

Порядок встраивания конфигурации, настройки, инструкции описаны в [Wiki](https://github.com/ASZykov/1c-mtp/wiki) проекта.
